## 在做

- [fstop](https://github.com/xqh-jason/fstop)（[在线试用](https://xqh-jason.github.io/fstop/)）—— 本地优先的语义图片搜索：CLIP 跑在浏览器里，照片不上传、不留副本。
- [tide-admin](https://github.com/xqh-jason/tide-admin) + [tide-server](https://github.com/xqh-jason/tide-server) —— 前后端分离的 RBAC 中后台：Vue 3 + Rust（Salvo / SeaORM），双凭证认证、接口级授权、写操作审计。
- [focusbar](https://github.com/xqh-jason/focusbar) —— macOS 菜单栏专注计时器：没有窗口、没有网络请求，常驻约 23 MB。
- [dsh-sidebar-delete](https://github.com/xqh-jason/dsh-sidebar-delete) —— DeepSeek Harness 侧栏删除插件：会话、本地日志、投影缓存、子会话一起清，零运行时依赖。
